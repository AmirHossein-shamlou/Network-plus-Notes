### Lecture 03: OSI Model & TCP/IP Comparison
- **Purpose of OSI:** A standard 7-layer model to help different network devices and vendors communicate with each other.
- **The 7 Layers (Top to Bottom):** Application, Presentation, Session, Transport, Network, Data Link, Physical.

- **The 7 Layers of the OSI Model (Top to Bottom):**
  1. Application (Data generation & user services)
  2. Presentation (Data formatting, encryption, and compression)
  3. Session (Session establishment, maintenance, and termination)
  4. Transport (Reliable/unreliable delivery, port numbers, TCP/UDP)
  5. Network (Routing and logical addressing - IP)
  6. Data Link (Switching, framing, and physical addressing - MAC)
  7. Physical (Cables, fiber optics, and raw bits transmission)
- **TCP/IP Model:** A more practical, streamlined 4-layer model that forms the foundational architecture of the modern Internet.
